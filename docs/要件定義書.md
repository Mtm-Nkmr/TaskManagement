# 要件定義書

## 1. アプリ概要

| 項目 | 内容 |
|---|---|
| アプリ名 | タスク管理アプリ（Trello風） |
| 目的 | タスクを視覚的に管理し、作業の進捗を把握しやすくする |
| 利用者 | 個人（自分だけ） |
| 動作環境 | Webブラウザ（Chrome推奨） |

---

## 2. 機能要件

アプリが「できること」の一覧です。

### 2-1. カラム（列）表示

- 「未着手」「進行中」「完了」の3列を表示する

### 2-2. タスクの追加

- 各カラムにタスク（カード）を追加できる
- タスクには「タイトル」と「期限」を入力できる

### 2-3. タスクの編集

- 追加済みのタスクの内容を後から変更できる

### 2-4. タスクの削除

- 不要なタスクを削除できる

### 2-5. タスクの移動

- タスクをドラッグ＆ドロップで別のカラムに移動できる

### 2-6. データの保存

- ブラウザのローカルストレージに保存する
- ページをリロードしてもタスクが消えない

---

## 3. 非機能要件

機能以外の条件です。

| 項目 | 内容 |
|---|---|
| 対応ブラウザ | Google Chrome（最新版） |
| データ保存先 | ブラウザのローカルストレージ |
| ログイン機能 | なし（個人利用のため不要） |
| スマホ対応 | 対応しない（PCブラウザのみ） |

---

## 5. 作らないもの（対象外）

最初のバージョンでは以下は作りません。

- ログイン・ユーザー管理
- 複数人での共有
- カラムの追加・削除
- タスクへの色付け・ラベル機能
- スマホ対応（レスポンシブデザイン）
