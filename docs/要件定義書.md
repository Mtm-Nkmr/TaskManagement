## 1. 背景・目的

### 背景

本アプリはWebプログラミングスクールの課題として作成するものである。フロントエンドからバックエンド・データベースまでを含むWebアプリケーション開発の基礎を学ぶことが目的である。

### 目的

- React（TypeScript）によるUI実装を習得する
- Java + Spring Boot によるバックエンド開発を習得する
- PostgreSQL を用いたデータベース設計・操作を習得する
- タスク管理というシンプルなドメインを通じて、CRUD操作の実装を習得する

---

## 2. アプリ概要

| 項目 | 内容 |
|------|------|
| アプリ名 | タスク管理アプリ（Trello風） |
| 概要 | タスクをカンバンボード形式で視覚的に管理し、作業の進捗を把握しやすくするWebアプリ |
| 利用者 | 個人（シングルユーザー） |
| 動作環境 | Webブラウザ（Google Chrome 最新版） |

---

## 3. 機能概要

詳細は [機能要件](機能要件.md) を参照。

| 機能 | 概要 |
|------|------|
| タスクの追加 | カラム（未着手・進行中・完了）にタスクを追加できる |
| タスクの編集 | タイトル・期限を変更できる |
| タスクの削除 | 確認ダイアログを経てタスクを削除できる |
| タスクの移動 | ドラッグ＆ドロップでカラム間を移動できる |
| タスクの手動並び替え | ドラッグ＆ドロップで同一カラム内を自由に並び替えられる |
| 期限切れの表示 | 期限が過ぎたタスクを赤字で視覚的に識別できる |
| タスクの期限順並び替え | カラムごとに期限が近い順に並び替えられる（手動順に戻せる） |
| データの永続化 | バックエンドAPIを通じてDBに保存し、リロードしても消えない |

---

## 4. 非機能要件

### パフォーマンス

| 項目 | 基準 |
|------|------|
| 画面の初回読み込み | 3秒以内 |
| API操作のレスポンス | 1秒以内（タスク100件以下の場合） |

### セキュリティ

| 項目 | 内容 |
|------|------|
| 入力バリデーション | タイトルの空文字・不正な日付形式などをAPIで検証する |
| SQLインジェクション対策 | SQLはプレースホルダーを使用し、文字列を直接結合しない |
| ログイン機能 | シングルユーザー構成のため不要 |

### エラー時の挙動

| エラーケース | 挙動 |
|------------|------|
| タイトルが空欄で保存 | モーダル内にエラーメッセージを表示する |
| API通信エラー | 画面上にエラーメッセージを表示する（操作は失敗として扱う） |

### アクセシビリティ

| 項目 | 内容 |
|------|------|
| Escキー | モーダル・ダイアログをEscキーで閉じられる |
| ボタンラベル | 各ボタンに操作内容がわかるラベルをつける |

### 対応環境

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Google Chrome（最新版） |
| スマホ対応 | 対応しない（PCブラウザのみ） |

## 5. 技術スタック・制約

| 項目 | 内容 |
|------|------|
| フロントエンド | React（TypeScript / Vite） |
| バックエンド | Java + Spring Boot |
| データベース | PostgreSQL |
| 利用者数 | 1名（マルチユーザー対応なし） |

---

## 6. 対象外

最初のバージョンでは以下は作りません。

- ログイン・ユーザー管理
- 複数人での共有
- カラムの追加・削除
- タスクへの色付け・ラベル機能
- スマホ対応（レスポンシブデザイン）
- タスクの説明欄
- タスクのピン止め
